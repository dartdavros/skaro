# TARDIS — модель версии 2005 года

Отдельный 3D-ассет и веб-анимация для будущей пасхалки.
Версия Девятого–Десятого Доктора. В интерфейс приложения пока не подключены.
На статическом сайте `skaro-dev/skaro-dev/index.html` пасхалка подключена
к существующей кнопке BAD WOLF на планете; это отдельная интеграция сайта.

## Файлы

- `tardis-2005.glb` — самодостаточная веб-модель со встроенными текстурами.
- `tardis-2005.blend` — исходная сцена Blender с упакованными текстурами.
- `textures/` — исходные PBR-текстуры, вывеска и дверная табличка.
- `renders/` — четыре статичных ракурса экспортированного GLB, PNG RGBA.
- `model-info.json` — размер файла, количество треугольников и соглашения.
- `source/` — воспроизводимая сборка модели, рендер и проверки результата.
- `web/` — анимация Three.js, управление воспроизведением и страница просмотра.
- `audio/tardis-noise.mp3` — предоставленная владельцем запись без перекодирования.
- `dist/` — результат отдельной веб-сборки (не хранится в Git).

В GLB нет фона, камеры, источников света и анимации. Прозрачность фона при
встраивании задаёт рендерер страницы, например `WebGLRenderer({ alpha: true })`.
Предоставленные PNG уже имеют прозрачный фон.

## Геометрия и материалы

Метры, Y вверх, лицевая сторона направлена по +Z. Размеры приблизительно
1,54 × 3,02 × 1,54 м. Начало координат находится в центре габаритов модели.

Корневой узел — `TARDIS_2005`. Три mesh-объекта:

- `Body_Mesh` — корпус, окна, надписи, крыша, основание и дверная фурнитура.
- `Lamp_Housing` — основание, каркас и колпак верхнего фонаря.
- `Lamp_Glass` — светящаяся часть с отдельным материалом `Lamp_Glass`.

У материалов корпуса обычный непрозрачный режим. В веб-анимации исчезновение
задаётся прозрачностью готового canvas, чтобы панели не просвечивали друг
сквозь друга. Свечение фонаря, мягкий ореол и локальный свет изменяются отдельно.
Стёкла окон имитируют мутное остекление
реквизита непрозрачной текстурой; интерьера и механики открытия дверей нет.

## Веб-анимация

Один запуск занимает 14 секунд: появление, пространственный эллипс с изменением
глубины, четыре вращения вокруг собственной вертикальной оси и исчезновение.
Размер меняется за счёт перспективы. Лёгкое затухание во время полёта остаётся
в пределах 78–100%; фонарь пульсирует с периодом 1,3 секунды. Фон прозрачный.
Траектория подстраивается под пропорции canvas. Запись `tardis-noise.mp3`
запускается вместе с полётом и останавливается при его завершении. Её примерно
13 секунд растягиваются до 14 секунд с сохранением высоты звука; повторов нет.
При повторном клике запись начинается заново, при паузе/скрытии вкладки
приостанавливается вместе с полётом. В начале и конце есть короткое затухание.

Сборка и только относящиеся к анимации тесты, из корня репозитория:

```powershell
npm --prefix assets/tardis ci
npm --prefix assets/tardis test
npm --prefix assets/tardis run build
```

`dist/flight-preview.html` содержит настоящую модель, запись и весь код; его можно
открыть локальным файлом в обычном браузере, без сети и сервера. Кнопка запускает
один полёт; повторный клик начинает его заново. Это просмотр отдельного ассета,
а не интерфейс Skaro и не проверка работающего приложения.

Для встраивания нужны `dist/tardis-flight.js`, `dist/tardis-2005.glb`
и `dist/tardis-noise.mp3`.
Использовать существующие canvas и кнопку страницы:

```javascript
import { createTardisFlight } from './tardis-flight.js';

const flight = await createTardisFlight({
  canvas,
  modelUrl: './tardis-2005.glb',
  audio: new Audio('./tardis-noise.mp3'),
});
easterEggButton.addEventListener('click', flight.play);
// При удалении сцены: снять обработчик кнопки и вызвать flight.dispose().
```

Canvas должен иметь заданный CSS-размер, прозрачный фон и `pointer-events: none`.
Его слой относительно контента задаёт страница. Сам модуль не добавляет HTML, кнопки и
продуктовые состояния. `play()` запускает заново; `pause()` оставляет текущий
кадр; `stop()` скрывает сцену; `seek(seconds)` показывает точный момент без
запуска времени; `dispose()` освобождает WebGL, текстуры и обработчики.
Опциональны `duration`, `onComplete`, `audio` и `onAudioError`. Без `audio`
модуль работает без звука. Ошибки воспроизведения передаются в `onAudioError`
(по умолчанию — в консоль); просмотр показывает их в существующем поле ошибки.
Неактивная вкладка приостанавливает время и звук.

Для страницы с `prefers-reduced-motion` решение о запуске остаётся за владельцем
интерфейса: модуль запускается только по явному вызову `play()`.

## Подключение к статическому сайту

`npm --prefix assets/tardis run build:site` собирает `dist/site/`:
`tardis-easter-egg.js` и `tardis-flight.css`. Они подключены на сайте из
`scripts/` и `styles/`. Исходник привязки — `web/site.mjs`.
Скрипт содержит реальные GLB, MP3 и точную копию PNG планеты для маски, чтобы
сохранить открытие сайта через `file://` без fetch, сервера и CDN. PNG для WebGL
декодируется из встроенного data URL, а не загружается из file:// DOM-картинки.
Новую маску брать из `web/planet-glow.png`; при замене картинки планеты на сайте
эту точную копию тоже нужно обновить. Новых кнопок и элементов управления нет.
Canvas добавлен прямо в body фиксированным слоем выше шапки и всех текстов;
его положение следует сцене с подъёмом на 15% её высоты. Начало и конец
наклонённого эллипса находятся за диском планеты. Ближняя дуга пологая;
на широких экранах максимальный размер ограничен, чтобы корпус и фонарь
оставались в экране во второй трети полёта.
На дальней половине орбиты модель и фонарь скрываются реальным альфа-контуром
изображения планеты, на ближней поднимаются перед планетой, заголовком и текстом,
выше окна приложения.
Нижняя граница полного вращающегося корпуса и фонаря измеряется заранее;
вся проекция эллипса поднимается с отступом 16 px от фактического верха окна.
При прокрутке и изменении размеров эта привязка обновляется без обрезки модели.
После этих сдвигов дальняя точка дополнительно привязана к видимой части диска
над окном. Размер дальней модели подстраивается под этот участок, чтобы начало
и конец целиком скрывались планетой. На ближней половине эта поправка исчезает.
Маска следует фактическим DOM-границам планеты при прокрутке и масштабировании;
свечение атмосферы не используется как непрозрачный диск.
Клики проходят сквозь canvas. До клика модель подготавливается без полёта и звука.
В отдельном просмотре без планеты маска отсутствует. Опциональный параметр
`occluderImage` принимает существующий HTMLImageElement планеты на странице.
`avoidElement` принимает DOM-элемент окна, выше которого должен оставаться полёт.
`anchorElement` привязывает фиксированный canvas к DOM-границам сцены.
`occluderTextureUrl` задаёт безопасный для WebGL источник той же маски;
в интеграции сайта это встроенный data URL исходного PNG.

## Референсы и точность

[Экранная версия 2005 года](https://thedoctorwhosite.co.uk/tardis/exterior/2005-tardis/)
и кадры из `Rose` и `New Earth` на той же странице. Это визуальная реконструкция:
размеры не сверены с обмерными чертежами BBC. Между сезонами реквизит отличался,
модель представляет общий внешний вид эпохи 2005–2010, а не каждый вариант.
Все встроенные текстуры изготовлены для этой модели; фотографии и сторонние
3D-модели в ассет не включены. Финальное сходство подлежит оценке владельца.

## Воспроизведение сборки

Нужны Blender 4.5, Python 3, Pillow, NumPy и системные шрифты Arial/Arial Narrow
из `C:/Windows/Fonts`. Python-зависимости перечислены в `source/requirements.txt`.
Шрифты в ассет не включены. В PowerShell из корня проекта:

```powershell
python assets/tardis/source/textures.py
blender --background --factory-startup --python-exit-code 1 --python assets/tardis/source/build.py
blender --background --factory-startup --python-exit-code 1 --python assets/tardis/source/render.py
python assets/tardis/source/check.py
```

В ограниченной среде `TMP` и `TEMP` должны указывать на доступный для записи
временный каталог. Сборка создаёт GLB и BLEND. Рендер заново импортирует именно
GLB; проверки читают конечный файл и четыре PNG. Сервисы приложения, HTTP-серверы,
API и подмена данных для этого не используются.
