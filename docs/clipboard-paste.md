# Вставка изображения до отправки

Поле ввода сохраняет существующую миниатюру 40×40 и прежние действия удаления
и отправки. Визуальный baseline не меняется.

`skaro-media` регистрируется до первой навигации окна. Обработчик ожидает
готовность настоящих сервисов: поздняя регистрация оставляла первый renderer
без схемы загрузки изображений до reload. Приёмка запускается с холодного окна
без reload; иначе эта неисправность скрывается.

Ctrl+V / Cmd+V начинает чтение системного изображения через существующий
`files.pasteImage`. DOM-событие `paste` использует тот же запрос; если Chromium
не предоставил пригодный File или не отправил событие для screen clip,
изображение добавляется из нативного буфера. Порядок завершения двух путей
не создаёт дубликат: вложения сравниваются по сохранённому пути с content hash.

Если после захвата фокус вернулся в ленту, видимый composer также обрабатывает
вставку изображения. Другие текстовые поля, редакторы и диалоги не перехватываются.

Файлы события захватываются синхронно, пока доступен DataTransfer. Для вставки
файлов из Проводника без bitmap сохраняется чтение их байтов. Обычный текст
проходит штатную вставку textarea. Пока сохранение изображения не завершено,
отправка ожидает завершения операции, чтобы не потерять вложение.

Приёмка должна включать именно установленный пакет и реальный захват Ножницами
с вставкой до отправки. Копирование уже открытого изображения в редакторе
Ножниц проверяет отдельный путь и не заменяет прямой screen clip. Дополнительно
проверяются обычный текст, PNG/bitmap, файл из Проводника, повторная вставка,
удаление и сохранность текста. Наличие DOM-узла миниатюры недостаточно:
проверяются naturalWidth/naturalHeight и фактическая компоновка.
