# Боковая навигация и список изменённых файлов

Прямое поручение владельца от 15.11.2026 уточняет существующий UI baseline:

- В активных задачах левой навигации перед названием показывается ID вида
  `T016`. Только мигающий индикатор работающей задачи справа заменяется
  существующей иконкой текущей активности агента: 12px вместо 14px на доске.
  Остальные индикаторы и свёрнутая навигация сохраняют прежнее поведение.
- Сводка отредактированных файлов в ленте сначала показывает три файла.
  Если остальные скрыты, нижняя строка «Показать еще N файлов» с иконкой
  раскрытия показывает весь список. После раскрытия та же строка показывает
  «Скрыть» с иконкой сворачивания и возвращает первые три файла. Заголовок,
  суммы строк и просмотр diff продолжают использовать полный набор файлов.
  Состояние списка сохраняется при прокрутке и повторном монтировании
  виртуализированной строки истории.
- В строке «Оставшийся лимит» статическая иконка заменяется белым круговым
  индикатором размером 20px; индикатор контекста возле модели остаётся 16px.
  Заполнение показывает минимальный известный остаток доступных окон.
  Неизвестное значение не подменяется нулём или полным лимитом.
  Подсказка при наведении и фокусе показывает каждое предоставленное агентом
  окно отдельной строкой: подпись и процент. Отсутствующее пятичасовое окно
  не показывается. Нажатие открывает прежнее окно лимитов; предупреждение
  об остатке ниже 10% сохраняется.

Источник данных лимитов — штатный `agents.limits` для агента проекта.
Изменения не добавляют API, искусственные данные или отдельные экраны.

Дополнение к удалению ресурсных ограничений: настройка количества одновременных
запусков и счётчик свободных слотов в окне запуска удалены. Состояние свободных
слотов больше не влияет на подписи и запуск задач и этапов. Автоматическое
слияние и очередность задач в общей рабочей копии сохраняют прежние элементы UI.
