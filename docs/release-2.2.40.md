# Skaro 2.2.40

Общий чат проекта может отвечать и записывать файлы в основную рабочую папку,
пока в ней выполняется задача. Защита используемой папки от удаления действует
до завершения работы.

Skaro быстрее готовит сообщение к отправке агенту. При открытии чата приложение
строит индекс памяти проекта один раз, читает независимые источники небольшими
группами и находит отдельные записи журнала ресурсов по идентификатору.

## Проверка

В штатном приложении на Windows, на проекте Cat-pilot с подпиской GPT, общий
чат ответил во время работы T-030. По следующему сообщению чат записал текущий
Git HEAD в основную папку, и выполнявшаяся задача прочитала его из файла.

В трёх новых чатах медиана времени до отправки запроса в Codex снизилась
с 2,53 до 1,61 с, а до первого текста ответа — с 13,19 до 12,44 с.
При холодном запуске первый текст пришёл за 17,44 с (до исправления — 17,21 с).
В этой сети Codex получил HTTP 403 при подключении по WebSocket и перешёл
на HTTPS после повторных попыток. В открытом чате первый текст следующего
ответа пришёл за 2,94 с. Эти замеры относятся к проверочному проекту на Windows.
