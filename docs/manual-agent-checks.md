# Ручная проверка совместимости агентов

По решению владельца от 02.10.2026 проверка запускается только вручную.
Расписание, ночной запуск и загрузка записей в CI не настроены.

В `apps/agent-probe` выполнить:

```sh
node src/canary.ts
```

Нужны Node.js из проекта, Git, установленные зависимости и действующая
авторизация настоящих закреплённых Codex и Claude Code. Стенд использует те же
адаптеры, что приложение, и отдельные файловые/Git fixtures. HTTP-заглушек нет.
Вызовы моделей расходуют лимиты аккаунтов.

По умолчанию оба агента выполняют `read`, `edit`, `question`. Отчёт проверяет
завершение хода, отсутствие ошибок и неизвестных элементов, ответ агента,
чтение файлов, результат правки запуском `test.js` и настоящее взаимодействие
вопроса. На Windows чтение Codex через PowerShell принимается по содержимому
прочитанных файлов, а не по обязательному типу `explore`.

Параметры:

```sh
node src/canary.ts --out /path/to/local-records
node src/canary.ts --baseline /path/to/local-records/run-previous
node src/canary.ts --scenarios read
```

`--out` задаёт родительскую папку: каждый запуск создаёт новый `run-*`.
Существующие записи и `fixtures/golden` не перезаписываются.
Без `--baseline` структура канонических событий сравнивается с golden-записями.
Сравнение игнорирует значения текста, идентификаторов, времени и количество
дельт; отчёт содержит хеши добавленных/исчезнувших структур. Такие различия
могут зависеть от ответа модели и требуют просмотра, сами по себе не означают
поломку адаптера.

Настоящий бинарник Codex экспортирует схему app-server с экспериментальными
полями в `codex-schema/`. `codex-schema-hashes.json` позволяет следующему запуску
сравнить состав и содержимое схем. Если предыдущего снимка нет,
`protocol.differences` равен `null`: схема экспортирована, сравнение не выполнено.
Изменение схем, неизвестное событие, ошибка или несостоявшийся сценарий дают
код выхода 1; успешная проверка — 0. Даже сбой запуска записывается в отчёт.

`report.json` содержит версии, платформу, итоги, счётчики и хеши без текстов
файлов и запросов. Raw/canonical-записи остаются локально и содержат текст;
санитизация путей и email не гарантирует удаления всех секретов. Перед передачей
записей требуется отдельная проверка содержимого. Стенд их не публикует.

Проверено 02.10.2026 на Windows x64: Codex 0.159.2 и Claude Code 2.1.285.
Правка и вопрос прошли у обоих; чтение повторено после исправления слишком
строгого ожидания `explore` и прошло у обоих. Неизвестных событий нет.
Экспортировано 440 схем Codex; повторный снимок совпал с первым.
Четыре узкие проверки отчёта, TypeScript и ESLint прошли.

Это минимальный ручной контроль. Он не заменяет реальные проверки sandbox,
изображений, фоновых задач, interrupt/resume/rewind и установки на каждой ОС
при смене pins или подготовке выпуска.
