# Skaro 2.2.47

- Общий чат выполняет работу напрямую, когда владелец не просит оформить задачи Skaro. План в тексте и работа с существующей задачей не требуют запуска планирования задач.
- По прямому поручению владельца агент общего чата может удалить указанную задачу через сервис доски или изменить её статус. Удаление использует штатную очистку ресурсов и зависимостей. Смена статуса сохраняет историю и сама по себе не сдаёт или не сливает результат.
- C4-ревью задачи в основной рабочей копии может использовать принятый коммит зависимости в качестве базы, когда этот коммит находится между настроенной базой и текущим `HEAD`. Изменения принятой зависимости не попадают повторно в область проверки задачи.

## Проверка

Прошли production-сборка, проверка типов, ESLint и 23 адресных теста. При рабочей отмене существующей задачи из общего чата Skaro сохранил ветку и историю и автоматически отменил инцидент без оставшихся активных задач.

Закреплённые версии агентов, Claude SDK и адаптеров совпадают с 2.2.46.
