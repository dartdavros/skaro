   обработчик паузы не добавляется.
2. Только одна ссылка в `index.html`:

   ```diff
   -  <script src="js/controls.js"></script>
   +  <script src="js/pause-controls.js"></script>
   ```

3. Независимый native C4 review, синтаксис и browser-сравнение реального
   Cat-pilot. Никакой новой функции, анимации, CSS или решения по 9 вопросам.

   окончательной проекции. Затем штатное восстановление сверяет реальные
   файлы, index, commit, C4/history и принятый SHA. Не повторяет model/write
   при неопределённом исходе; неизвестный результат удерживается до сверки.
6. Подтвердить один опубликованный эффект, одну запись merge/history,
   сохранность посторонней работы и всех planned/current, завершить задачу
