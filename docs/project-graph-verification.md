В настоящем рабочем профиле `%APPDATA%/Skaro` сохранено раскрытие файла
внутри свёрнутой группы. Оно не меняло проекцию, но отключало готовый обзор:

перестраивают проекцию. Read-only регрессия сравнила результат с полным
пересчётом, включая evidence, связи и счётчики, и проверила раскрытие предка.

по 194 узла и 646 связей. Таймаутов и renderer-ошибок нет; сохранённые
фильтры, раскрытия, выбор и хэши C4/архитектуры не изменились.
Скриншоты открытого и восстановленного графа просмотрены. Сборка,
desktop main TypeScript, целевой ESLint и `overview-cache-live.test.ts` прошли.
Заглушки, fixtures, seed-данные и вызовы моделей не использовались.
Артефакты: `output/graph-timeout-*.log`, `output/graph-timeout-before.json`,
`output/graph-timeout-after.json` и каталог текущей сессии `graph-timeout`
в `C:\Users\drmar\.codex\visualizations\2026\10\21\01a15fdc-418c-79c2-af75-8e4273bf4b25`.

`graph-feature-live.spec.ts` проверяет:

- Фоновое построение до первого открытия C4/графа; готовый снимок через IPC.
- Совпадение модели и всех 39 сценариев, точный порядок relationship IDs.
- Scope, cursor/pagination, evidence/source hash, запрет чужого корня,
  исключённых файлов и устаревшего исходника; путь и HTTP-кандидат клиент → Django.
- Живую карту, паузу/продолжение движения, сценарий на паузе, шаг и воспроизведение.
- Ручной масштаб графа 150% и C4 125%, восстановление при неверном значении/Escape,
  сохранение камеры. C4/граф доступны из основного меню после задач.
- Группу «Прочее» и отсутствие отдельных C4/графа в дереве документов.
- Реальную ошибку открытия отсутствующего planned-пути: алерт имеет
  18 px слева/справа, 8 px сверху и 12 px снизу; закрывается штатной кнопкой.
- Отмену перестроения с сохранением последнего снимка, отсутствие ошибок renderer.
- Отсутствие `database is locked` и ошибочного статуса после открытия графа,
  при фоновой очистке накопленных снимков. Чтение открывает SQLite read-only;
  очистка выполняется короткими порциями с паузами и возобновлением по журналу.

## Исправления по замечаниям владельца от 21.10.2026

Проверка в штатном Electron на настоящем Chatballs, без заглушек. Артефакты:

- Desktop `tsc` прошёл; финальный svelte-check — 0 ошибок и предупреждений.
  ESLint изменённых файлов прошёл; компоненты <180 строк, модули кода <300.

- `graph-feature-live.spec.ts` пройден после изменения входа в C4 и проверки

  из архитектурного объекта, поскольку внутренний файловый узел C4 скрыт.
- В последнем `graph-defects-live.spec.ts` прошли проверки списка C4 и возврата,

  Приоритет новых записей и исходный порядок сохранены; миграция остаётся

  отсутствующей коллекции не создаёт маркер миграции, сохранённые записи
  доступны через `all/get`. БД профилей не изменялись, данные не генерировались.
  Непустая немигрированная legacy-коллекция отдельно не проверена: в доступном
  реальном профиле такие коллекции уже мигрированы.

  не ослаблялась. Результаты: `output/db-readonly-tests.log`,

## Непроведённые проверки

Изменение/удаление/переименование реальных файлов, переключение веток/worktree
и равенство инкрементального/полного индекса не проверялись мутациями Chatballs:
checkout используется только для чтения. Watcher и восстановление очереди
реализованы, но эти сценарии не отмечаются проверенными данным тестом.

Не проведены полный анализ Skaro как второго checkout, проверка установочных
пакетов всех OS/архитектур, принудительная потеря WebGL, длительный профиль утечек,
проверки всех адаптеров на неоднозначных случаях и измерение p95/памяти по PG-0.
Бюджеты из плана остаются предложенными целями. Полный набор тестов не запускался
на этапе реализации по правилу владельца; выполнялись только затронутые проверки.
После поручения выпуска 2.2.0 владелец отдельно разрешил полный релизный suite;
его результаты фиксируются в подготовке выпуска и GitHub Actions.
