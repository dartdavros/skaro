# Skaro 2.2.49

- Skaro может подготовить частичную публикацию GitHub Actions workflow для задачи с незавершёнными проверками. Для согласованного PR проверяются репозиторий, базовая ветка, точный коммит и файл workflow. Публикация файла и выполнение оставшихся критериев приёмки учитываются отдельно.
- Чаты и задачи сверяют предупреждение о лимите Codex с актуальными данными аккаунта при открытии сохранённой истории.
- При ошибке Mermaid исходный текст остаётся внутри сообщения или документа. Во время потокового ответа отрисовка незакрытого блока откладывается до его завершения.
- При выгрузке диагностики Skaro сохраняет разовый замер резидентной памяти по процессам приложения и его дочерним процессам. При ограничениях системы отчёт указывает доступную область замера. Пути, команды запуска и содержимое чатов в снимок памяти не входят.

Отрисовка Mermaid и экспорт памяти проверены в штатном Electron на Windows с Cat-pilot. Причина сообщённого расхода 10–15 ГБ на Mac пока не установлена. Для диагностики такого случая отчёт следует выгружать в момент роста памяти.
