# Skaro 2.2.39

Выпуск исправляет зависание служебных инцидентов и миниатюру изображения
до отправки сообщения. Pins агентов, SDK, адаптеров и lockfile не меняются.

## Изменения

- Инциденты завершённых, отменённых и архивных задач закрываются без запуска
  агента. Общий инцидент сохраняется, пока остаётся незавершённый подписчик.
- План восстановления требует выполнимой проверки до предложения решения
  владельцу. Ответ владельца сам по себе не считается доказательством исправления.
- Несовместимые старые планы перестают блокировать повторную диагностику.
  Проверка провайдера не принимается для неподдерживаемой внешней причины.
- Настоящий выход процесса агента получает отдельную проверку: контроллер
  связывает инцидент с записанным падением и подтверждает последующий живой ход.
  Это не доказывает восстановление внешнего сервиса и не отменяет Stop или отказ.
- `skaro-media` регистрируется до первой навигации окна. Раньше сохранённое
  изображение могло оставаться сломанной миниатюрой до reload интерфейса.
- Ctrl+V читает нативное изображение также при фокусе в ленте после захвата
  экрана. Другие редакторы и диалоги не перехватываются. Сохранены текст,
  удаление, защита от дубликатов и существующая геометрия миниатюры 40×40.

## Проверки и ограничения

Прошли сборка, проверка типов TypeScript/Svelte, lint изменённых файлов,
11 адресных тестов в 8 файлах и проверка размеров модулей.

На зарегистрированном Cat-pilot с настоящими сервисами прошла browser-проверка
холодного запуска без reload: PNG, Windows bitmap и файл из Проводника,
декодированные пиксели миниатюры, повторная вставка, удаление, сохранность текста,
вставка с фокусом в ленте и отсутствие перехвата в поиске файлов. Компоновка
проверена по снимкам фактического окна.

Подготовленный пакет прошёл настоящий выход процесса Codex: записан
`Codex stopped (1)`, запущен диагностический ход, условие проверено контроллером,
инцидент разрешён и блокировка продолжения снята. Штатное закрытие этого
проверочного экземпляра превысило таймаут; завершалось только его собственное
дерево процессов. Нормальное закрытие этим прогоном не подтверждается.

Отдельно на установленной 2.2.38 воспроизведено отсутствие миниатюры при фокусе
в ленте. Прямая последовательность Win+Shift+S → Ctrl+V в установленной 2.2.39
не проверена. По указанию владельца обновление установленного приложения
выполняет сам владелец; подготовленный пакет не выдаётся за установленную версию.

Локальные установочные пакеты удалены по поручению владельца. Публичные шесть
установщиков и метаданные выпускаются штатным workflow по [контракту](updates.md).

Для 2.2.39 владелец явно разрешил полный штатный CI/release suite с существующими
изолированными fixtures и HTTP test servers, а также использование прежних
принятых canary/model-проверок неизменённых pins. Используются `check_scope=full`,
`test_fixtures_allowed=true`, `agents_verified=true`; новый canary не заявляется.
