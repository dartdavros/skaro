# Приёмка общего окружения и сохранности worktree

15.11.2026 выполнена живая проверка на зарегистрированном Cat-pilot.
Службы ограничены через `catPilotState` до `createServices`. Использовались
настоящие Codex, MCP и штатный Compose проекта; подставных сервисов не было.

## Запуск в основной папке

В T-030 агент работал в основной рабочей копии без worktree и использовал
существующий `cat-pilot-dev-web-1`, сохранив ID и mounts. HTTP `/` и
`/index.html` вернули 200 с побайтовым совпадением локального HTML;
`node --check js/motion-controls.js` завершился с кодом 0.

Агент следовал инструкции in-place и не вызывал инструменты изолированной
копии. Их защитные ответы отдельно проверены через настоящий scoped MCP:
`start_environment` и `configure_environment` вернули пояснение режима,
не потребовали checkout и не заявили о проверенной готовности сервисов.

Отчёт в userData:
`verification/environment-isolation-fd9b510c-9a04-4259-9e99-d94bfb789e66/proof.json`.

## Смена настройки при работающей задаче

В T-032 сначала штатно запущено собственное окружение задачи. Во время
60-секундной команды, читающей существующий `index.html`, настройка проекта
изменена с worktree на in-place через штатный сервис настроек.

При работающей команде сохранились run ID, путь и режим задачи, HEAD,
SHA-256 всех 21 файла, ID контейнера, его StartedAt и mounts. HTTP окружения
оставался доступен и отдавал HTML данного worktree. Все 12 чтений завершились
с одинаковыми cwd и SHA-256, код команды — 0. Повторный `start_environment`
в той же агентской сессии сохранил рабочее окружение и адрес; HTTP вернул 200.

Отчёт в userData:
`verification/environment-isolation-a10c10eb-0017-4faa-b19f-695ca629e416/proof.json`.
Раздел `postShutdown` дополнительно подтверждает сохранность файлов и контейнера
после штатного завершения служб; контейнер остановлен, worktree не удалён.

## Восстановление и границы

По отдельному разрешению владельца временно освобождён основной checkout,
который удерживала остановленная T-006. Её файл и исходный config восстановлены
побайтово. Проверочные задачи остановлены и архивированы без удаления истории.
Общий контейнер возвращён в исходное остановленное состояние.

Первые попытки T-028 и T-031 заблокированы настоящим `budget_disk` и не считаются
приёмкой переключения. После отдельных разрешений владельца очищены
неиспользуемый Docker build cache и старые сборки `apps/desktop/release`.
Лимиты и резервы допуска не снижались; контейнеры, тома и данные не удалялись.
