# Skaro 2.2.50

- Модель C4 строится по кнопке в разделе C4. Запуск задачи, приёмка результата и слияние больше не зависят от архитектурного аудита.
- Агент ведёт задачу без проектного координатора. Блокировки остаются в истории задачи. Общий проектный чат и его история сохранены.
- Кнопка «Доделать» сохраняет команду продолжения для конкретной задачи. При восстановлении Skaro использует сохранённую карточку, а повторная доставка старой команды учитывает явную остановку владельцем.
- Исправлено восстановление отправленных результатов и незавершённых операций слияния. При проверке результата Skaro сверяет принятый коммит с состоянием Git.
