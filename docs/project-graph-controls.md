# Дополнительные управления полного графа: решение по дизайну

21.10.2026. Основной вид утверждён владельцем по превью с шестью поправками.
Фильтры, пути/влияние и пошаговый проигрыватель описаны в спецификации, но
не показаны в утверждённом превью. Ниже — конкретная компоновка для согласования.

Оболочка, существующие размеры, типографика, холст, легенда и частицы остаются
как в превью. Главное меню: Задачи → C4 → Граф связей → Документы → План.
Обычные C4-превью документов сохраняются. Подгруппа документов — «Прочее».

## Фильтры и поиск

Первая строка — существующие Select «Представление» и TextField поиска из превью.
По последующему указанию владельца от 21.10.2026 отдельная строка фильтров
состояния архитектуры, слоёв, типов связей и «Происхождение и ограничения» убрана.
Поиск выдаёт результаты существующими SelectOption и открывает объект на карте.
Легенда и два тумблера остаются под управлениями; тумблер примыкает к своему тексту.

## Детали, раскрытие, путь и влияние

Для архитектурного объекта сохраняется C4Details. Для кода/документа/события
панель использует те же классы и иерархию: вид → название → происхождение и
состояние → описание → источники → соседи. Агрегированная группа показывает
число исходных объектов и действие «Раскрыть» существующей кнопкой.

Внизу деталей используются существующие Button и Select:
«Начало пути», «Конец пути», «Найти путь», направление и глубина;
«Влияние изменений» с глубиной и выбранными типами зависимостей.
Результат подсвечивается на общей карте. Ограниченный поиск явно отличается
от завершённого поиска без результата. Есть переходы назад/вперёд по выбору.
Список источников открывает существующий просмотрщик файлов, с проверкой хэша.

## Проигрыватель

При выборе сценария между навигацией и легендой появляется ещё одна строка
того же `c4-viewer-nav`: IconButton «В начало», «Предыдущий шаг»,
«Воспроизвести/Пауза», «Следующий шаг», Select шага и Select скорости 0.5×/1×/2×.
Отдельная строка существующей типографикой показывает полный текст текущего шага,
номер N из M и архитектурное состояние. Моделируемый шаг не называется успешным.
Сценарий открывается на паузе; контекст карты сохраняется. Таймер останавливается
при уходе из раздела, скрытии окна или обновлении основания.

## Служебные состояния

Загрузка, обновление, неполное покрытие, устаревание, отсутствие модели/исходников,
ошибка и отсутствие WebGL используют существующие LoadingView/Banner/Button,
без новых карточек, иллюстраций, цветов и иконок. Доступны отмена построения
и повторное построение. Footer показывает количество загруженных/скрытых объектов
и основание анимации. Полный экран использует тот же холст и те же управления.
