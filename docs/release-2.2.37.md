# Skaro 2.2.37

Выпуск объединяет текущие исправления агента, координации операций и ленты.
Номер выше установленного локального комплекта 2.2.36; публичная предыдущая
версия — 2.2.35. Версии закреплённых агентов, SDK и адаптеров не меняются.

## Изменения

- Если продолжение требует разрешения владельца, агент запрашивает конкретное
  действие через существующую карточку согласования вместо неопределённого
  блокера «укажите решение». Отказ не разрешает выполнять действие.
- Незавершённая сдача результата задачи больше не блокирует создание чата
  проекта. Старые регистрации чатов сохраняют идентичность и требуют явного
  повтора владельцем после восстановления.
- Сдача результата сохраняет достоверный исход и идентичность операции.
  `reconcile_task_submission` сверяет исходную операцию без её повторного
  исполнения, сброса Stop, изменения критериев или запуска сервисов.
- Отпечатки C4 и большие Git diff обрабатываются потоком; диагностика ошибок
  и ответы сдачи ограничены по размеру, чтобы не создавать повторный сбой связи.
- Принятый результат в основной рабочей копии сохраняет точный SHA до проекции
  завершения. Снимок использует отдельный Git index и сохраняет HEAD владельца.
- После отправки сообщения или ответа сразу видна существующая индикация
  обработки, включая ожидание первого события агента.
- Развёрнутый список изменённых файлов можно снова свернуть.
- Индикатор остатка лимита увеличен до 23px, использует прямые концы дуги
  и красный цвет при остатке 10% или меньше.

## Проверка и выпуск

Адресные проверки используют настоящий Git, SQLite и чистые metadata DTO.
Локальная сборка и проверки типов выполнены; окончательный полный CI и сборка
шести установщиков выполняются штатным release workflow после требуемых
подтверждений владельца. Рабочий Skaro остаётся открытым; новая живая проверка
на Cat-pilot и локальная установка этим выпуском не выполняются.
