# Актуальный UI baseline Skaro v2

Актуализировано 01.10.2026 по указанию владельца: утверждённый дизайн уже
реализован в коде. Старые HTML-макеты удалены из рабочего дерева и больше
не являются источником дизайна. Их наличие в истории Git не разрешает
восстанавливать прежний интерфейс.

## Источник и приоритет

1. Прямые указания владельца по текущей задаче.
2. Текущая реализация интерфейса в `apps/desktop/src/renderer/src/` и
   общие компоненты, иконки, токены в `packages/ui/src/`.
3. Актуальные описания согласованного поведения в документах ниже.

Этот документ фиксирует существующий интерфейс и порядок его изменения.
Он не объявляет все функции реализованными или проверенными: остаток работы
и ограничения проверки перечислены в [плане реализации](implementation-plan.md).

Задания `design-brief-*.md` сохраняются как история решений. Их старые размеры,
палитра, расположение панелей, примеры и требования «дорисовать» или «перенести
из макета» не являются текущим заданием. При противоречии сохраняется дизайн
в коде; не возвращать старый вид по историческому документу.

## Зафиксированные решения

- По поручению владельца от 21.10.2026 порядок основных разделов:
  Документы → C4 → Граф связей → План → Задачи. Подсказки разделов показываются
  только в свёрнутом меню. В чатах проекта и задач нижний отступ поля ввода
  увеличен на 5px; индикатор усилия из вертикальных полос убран. Сводки групп
  действий и строки внутри них используют 12px; общая анимированная иконка
  активности агента в ленте и доске — серый `--sk-text-21`.
  В правом верхнем углу обоих чатов доступна очистка истории с подтверждением:
  после завершения/остановки агента начинается новая беседа без прежнего
  контекста, файлы, рабочая копия, результаты и состояние задачи сохраняются.
  Незавершённое применение подтверждённых изменений сначала нужно завершить.
  Состояния групп документов сохраняются отдельно для каждого проекта.
  По последующему уточнению владельца построение и начальная компоновка графа
  и C4 обозначаются общим спиннером без декоративной анимации. Миниатюры C4
  сохраняют высоту области диаграммы при загрузке, спиннер находится по центру.
  Очистка общего чата использует существующий хедер. В чате задачи кнопка
  находится в правом верхнем углу области переписки без отдельной строки;
  при свёрнутом описании — в существующем хедере этой же области.
  Текстовая ссылка «Открыть диаграмму» убрана. Вид списка/плитки
  переключается тем же общим компонентом, что и доска задач.
  По уточнению владельца список C4 — компактные строки названия, уровня
  и состояния в существующем стиле списка задач, без миниатюр и их компоновки.
  Плитка показывает карточки с миниатюрами. Нажатие C4 в левом меню всегда
  открывает корневой список/плитку, в том числе из детальной диаграммы и после
  перехода из графа; выбранный вид списка/плитки сохраняется.
  По следующему указанию владельца галерея C4 фильтруется по типу диаграммы
  и состоянию компонентами доски задач. Тип и состояние карточки перенесены
  вправо в её подвал, перед названием показана иконка типа диаграммы.
  Визуальную проверку этих изменений владелец выполняет самостоятельно.

- По дополнению владельца от 21.10.2026 плитка C4 показывает две колонки,
  когда доступная ширина содержимого галереи достигает 960px; ниже — одну.
  Второй сайдбар чатов расширен с 224px до 248px, справа у списка есть отступ
  6px до полосы прокрутки и 14px до края панели. Загрузка экранов, чатов
  проекта, задач и страниц истории обозначается общим вращающимся индикатором
  LoaderCircle в существующем цвете `--sk-text-21`; reduced motion отключает
  вращение. Индикатор доступен до загрузки стилей ленты. Это согласованные
  текущим поручением изменения baseline.

  По последующему поручению владельца загрузка видимой ленты и её Markdown
  объединена одним общим индикатором; резервные строки истории своих спиннеров
  не показывают. Ошибка чтения прекращает индикацию и выводится штатным баннером.
  Кнопка остановки чата на время запроса недоступна и отмечена `aria-busy`;
  ошибка выводится штатным баннером. Визуальную проверку этих правок выполняет
  владелец; прежняя browser-проверка ниже их не покрывает.

  Целевая native-проверка `chat-loading-live.spec.ts` прошла в штатном Electron:
  две browser-проверки, реальные сохранённые чат и задачи, ширины окна 1500/1050px,
  появление индикатора до ответа и исчезновение после чтения/отрисовки Markdown.
  Скриншоты просмотрены. Лог — `output/chat-loading-browser-verified.log`;
  сборка — `output/chat-loading-build.log`, Svelte — 0 ошибок/предупреждений.
  Предыдущий повторный прогон ошибочно требовал спиннер для уже кешированной
  задачи; проверка исправлена выбором настоящей задачи без сохранённого viewport.
  Заглушки, генерация данных и запуск агентов не использовались. Ускорение
  произвольных тяжёлых историй этим изменением не подтверждено.

- По уточнению владельца от 21.10.2026 раздел C4 сначала показывает список
  миниатюр существующего C4Preview. Нажатие открывает диаграмму, закрытие
  возвращает к списку; переход к конкретному элементу из графа открывает её сразу.
  Фон шапки диаграммы совпадает с фоном графа (`--sk-bg`). Выпадающие меню
  прокручиваются и остаются в окне; фильтры слоёв, связей, происхождения,
  оснований, языков и подсистем используют существующий FilterMenu с мультивыбором.
  Документы `.skaro` полностью скрыты из графа и его поиска; принятая C4 остаётся
  источником архитектуры. Баннер построения можно скрыть без отмены построения.
  «Покрытие анализа» открывает статистику разбора и ограничения над нижней панелью.
  Движение узлов — плавный переход к раскладке по реальным связям с остановкой
  после сходимости; бессрочное декоративное покачивание убрано. При выделении
  текста доступна кнопка «Скопировать». Пустой экран проектов использует актуальную
  иконку приложения из `apps/desktop/build/icon.png`.

- Внутренняя группа документов называется
  «Прочее». Вид живой карты основан на утверждённом превью, дополнительные
  управления — на [согласованной компоновке](project-graph-controls.md).
  Процент масштаба C4/графа редактируется в прежней надписи без поля ввода.
  Состояние реализации и визуальной приёмки — в [плане графа](project-graph-plan.md).

- По последующему указанию владельца от 18.10.2026 приложение восстанавливает
  последнюю активную вкладку, раздел, задачу или чат. Это заменяет прежнее
  указание о принудительном открытии главной страницы. Реестр проектов и
  сохранённое представление доступны до запуска тяжёлых сервисов; сводки
  обновляются независимо. Проверка наличия готового агента сохраняется.

- По тому же поручению существующая карточка вопроса закреплена над полем
  ввода, вне прокручиваемой истории. До полного ответа на все вопросы сессия
  остаётся в состоянии ожидания. Внешний вид карточки и её варианты сохраняются.

- По поручению владельца от 16.10.2026 C4 в архитектуре и спецификациях
  показывается превью на всю ширину документа. Нажатие открывает отдельный
  холст с масштабированием, перемещением и полным экраном. Оформление всех
  представлений централизованно задаёт Skaro; агенты передают модель.
  Пакет модели и связанных документов принимается одной существующей карточкой
  diff и просматривается последовательно в её просмотрщике. Выбор компонентов,
  визуального оформления и качество реализации поручены агенту без отдельного
  согласования дизайна. Подробности — [C4](c4.md).

- По указанию владельца от 10.10.2026 в строке ошибки завершения хода
  («Запуск прервался: …») текст действия «Перезапустить» заменён кликабельной
  существующей иконкой `reset`. Подсказка действия сохранена; остальные
  элементы строки и предупреждение о потерянной сессии не меняются.

- По согласованию владельца от 08.10.2026 клик по ссылке окружения в ленте
  задачи запускает ручной просмотр. Над лентой используется существующий
  `Banner` вида `info`: «В очереди», «Запускает окружение…» или
  «Окружение запущено для просмотра». Во всех трёх состояниях доступно действие
  «Завершить просмотр», отменяющее ожидание или завершающее просмотр.
  Английские тексты: «Queued», «Starting environment…»,
  «Environment is running for review», «Finish review».
  Ошибки показываются существующим баннером ошибок. Новые иконки, стили,
  экраны и модалки не добавляются. Само открытие чата сервисы не запускает;
  переключение чата и потеря фокуса просмотр не завершают.

- По поручению владельца от 08.10.2026 перепланирование фактически не начатых
  задач подтверждается одним пакетом через существующую карточку diff:
  заголовок агента, полный результат по «Открыть», кнопки «Отклонить» и
  «Применить». Стили, иконки и layout карточки изменений сохраняются.
  По дополнительному согласованию от 09.10.2026 эта же карточка показывает
  фактический прогресс применения/отката и конкретный итог, например `55 → 25`.
  После успеха доступны «Открыть задачи» и безопасное действие «Откатить»;
  в конец ленты добавляется сохраняемое уведомление Skaro без вызова модели.
  Применение начинается после решения владельца по пакету в обоих режимах
  доступа агента. Ошибки используют существующее отображение.
  Контракт и ограничения — [task-replanning.md](task-replanning.md).

- По последнему указанию владельца от 07.10.2026 подтверждается весь план одним
  действием: одна карточка всех задач с указанием этапов, один набор кнопок
  «Отклонить» / «Подтвердить план». Сохраняются существующие стили и компоненты.
  Выбор задачи включает зависимости, снятие зависимости снимает зависимые задачи;
  подсказка флажка объясняет это. Созданные задачи при восстановлении фиксированы.
  После подтверждения нет ожидания других карточек, переходов к предшественникам
  и кнопки «Повторить». Старое решение с отдельным принятием этапов отменено.
  См. [подтверждение полного плана](project-planning.md).
- По указанию владельца от 07.10.2026 общий чат готовит спецификации и планирование сам; этапы можно создавать без задач. Согласовано состояние текущей карточки пустого этапа: заголовок «Этап Mxx „Название“», существующие кнопки «Отклонить» и «Принять», без списка задач и его подсказки. Стили, иконки и расположение существующих элементов сохраняются. См. [карточки предложений](agent-output.md#54-чаты-проекта-карточки-предложений).

- По указанию владельца от 06.10.2026 остаются чат задачи и общий чат проекта.
  Этап не открывает собственную ленту или сессию приёмки. Пункт открытия чата
  этапа убран; «Влить готовое» показывает существующую карточку в чате задачи.
  Остальной визуальный baseline сохраняется. Процесс описан в
  [завершении задач и релизов](completion-process.md).

- По указанию владельца от 05.10.2026 лента во всех чатах ограничена шириной
  720 px и расположена по центру; поле ввода остаётся чуть шире — максимум
  744 px. На узком экране оба элемента занимают доступную ширину.
- Усилие по умолчанию — `high`, независимо от собственного значения модели.
  Явный выбор другого поддерживаемого усилия сохраняется. Изменение агента,
  модели или усилия проекта применяется ко всем неначатым задачам, включая
  ожидающие очереди; после первого запуска параметры задачи фиксируются.

- По указанию владельца от 05.10.2026 общая анимация живой строки заменена
  предоставленными SVG: `brain`, `hammer`, `clock-fading`, `shapes`.
  Фиксированный мягкий розовый цвет — `#ee9cbd`, без связи с темой Windows.
  По последнему уточнению владельца формирование ответа тоже показывается как
  «Думает…» с пульсирующим мозгом; перо и текст «Пишет ответ…» убраны.
  «Готовит правку…» — стучащий молоток; по указанию владельца от 08.10.2026
  «Ждёт ответа модели» — предоставленные песочные часы `hourglass.svg`:
  частицы сыпятся сверху вниз 3 секунды, затем часы переворачиваются за
  0,6 секунды и цикл повторяется. Цвет сохраняется розовым `#ee9cbd`.
  «Запускает окружение» — фигурки, вращающиеся вокруг собственных центров
  с разными скоростями и направлениями. По последнему уточнению владельца размеры
  изменены: по указанию от 08.10.2026 мозг с одобренными бликами внутри
  извилин — 18 px в ленте; остальные иконки активности — 16 px.
  На доске сохраняются 14 px. У выполняющейся задачи в колонке
  «В работе» точка заменена
  той же анимированной иконкой текущей активности; очередь и остальные статусы
  сохраняют свои обозначения. При ограничении анимаций в ОС иконки статичны.
  По следующему уточнению владельца по тексту текущего состояния в ленте
  слева направо проходит короткий светлый блик с паузой между повторениями.
  При ограничении анимаций в ОС текст также статичен.
  По последнему уточнению владельца круг окружения слегка пульсирует без
  вращения по вертикальной оси; остальные фигуры продолжают вращаться.
  Текст текущего состояния увеличен на 1 px до размера основного текста ленты.

- По указанию владельца от 08.10.2026 в новой задаче сразу после клика
  «Начать» кнопка заменяется одобренным мозгом с пульсацией и бликами
  размером 96 px (×6 в предпросмотре). Под ним — «приступаю...».
  Во время запуска старые иконка, заголовок и пояснение пустой задачи
  скрыты: остаются только мозг и подпись.
  Индикатор сохраняется до появления ленты; получение ответа на запрос
  запуска само по себе его не убирает. При появлении ленты индикатор
  исчезает. Ошибка запуска и постановка в очередь используют существующие
  состояния экрана. Повторный клик во время запуска не отправляет новый запрос.

- По указанию владельца от 05.10.2026 карточка задачи со статусом «В очереди»
  на доске показывает индикатор в правом верхнем углу. По последнему уточнению
  владельца это часы `Icon name="clock" size={13} stroke={2}` с синей кнопки
  «В очередь этапа». Индикатор также показывается в колонке «Не начата» у задач,
  ожидающих предыдущую задачу этапа: доска получает тот же `after`, что экран
  задачи. У обычной неначатой задачи часов нет. Подсказка — «В очереди».
  При запуске задачи часы сменяются иконкой активности; остальные статусы
  сохраняют свои обозначения, в том числе замок у заблокированных задач.

- По указанию владельца от 05.10.2026 внизу сайдбара проекта добавлен пункт
  «Оставшийся лимит» с иконкой `circle-gauge` и существующим разделителем над ним.
  По следующему указанию владельца текст уменьшен до 13 px; справа показывается
  меньший остаток окон агента по умолчанию, когда он ниже 10%, с обновлением
  каждые три минуты. В свёрнутом сайдбаре процент находится в подсказке.
  Компактная модалка использует существующие переключатели агентов и компоненты;
  выбран агент по умолчанию проекта, ниже показаны остатки на пять часов и неделю.
  См. [лимиты подписки](agent-limits.md).

- По указанию владельца от 05.10.2026 существующий выбор агента задачи доступен
  после остановки/ошибки, между ходами и в ожидании. Во время выполнения
  сначала требуется остановка. Сохраняются текущая модалка, компоненты и layout;
  меняются доступность выбора, пояснение блокировки и стандартная строка
  уведомления в ленте. Изоляция начатой задачи фиксирована. См.
  [передачу работы](agent-handoff.md).

- Проект открывается на «Задачах». Порядок разделов: «Задачи», «Документы»,
  «План», разделитель, «Чат», «Параметры». Отдельного «Обзора» нет; его удаление
  ранее согласовано в третьей итерации задания дизайнеру.
- Навигация проекта слева. На экране задачи лента и поле ввода в центре,
  описание справа. Ширина и сворачивание панелей сохраняются. Подробности:
  [расположение панелей](sidebar-layout.md).
- Соседние действия объединяются в группы. Группа и вывод команды изначально
  свёрнуты; новые события не меняют выбранное пользователем раскрытие.
  Завершённые размышления не выводятся отдельными строками. Подробности:
  [вывод агентов](agent-output.md), разделы 5 и 7.
- Общий крестик ошибки у группы действий убран. Историческая неудачная команда
  сохраняет свою индикацию внутри группы. Подробности:
  [слияние задач](task-merging.md).
- Карточка слияния уже реализована в ленте. Отдельное ревью не добавляется.
  Worktree и ветка сохраняются после слияния. Подробности:
  [архитектура](architecture.md), [окружения задач](task-environments.md).
- Чат проекта поддерживает «Спрашивать» и «Полный доступ». Старое требование
  «чат только читает код» заменено согласованными режимами.
- Кнопка и модалка обновлений реализованы. Их поведение и ограничения проверки:
  [обновления](updates.md).

## Изменения и проверка

- Сохранять существующие структуру, порядок, тексты, иконки, токены, размеры,
  состояния и поведение. Новые элементы и отклонения требуют прямого решения
  владельца; отсутствие согласованного дизайна — design gate.
- Перед UI-правкой изучить затронутые компоненты и актуальные документы.
  Сверять результат с текущим интерфейсом до изменения и разрешённой правкой.
- Browser-проверку проводить в настоящем Electron со штатными сервисами.
  Preview с `mock-bridge.ts` не подтверждает работу локального проекта.
  Не создавать или запускать заглушки без отдельного разрешения владельца.
- Если штатный контур недоступен, сообщить blocker. Наличие компонента или
  статическая сверка исходников не заменяют проверку рабочего сценария.
